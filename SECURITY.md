# Security Policy

## Reporting a vulnerability

Lyncus parses untrusted files, so parser bugs can be security bugs.
If you find a way to crash Lyncus or make it misbehave with a crafted file,
please do not open a public issue. Use GitHub's "Report a vulnerability"
button on the Security tab instead.

## Samples

Never attach live malware to issues or pull requests. Share the SHA-256 hash.
